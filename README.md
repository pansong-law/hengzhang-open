# 衡账｜给律师用的律师费管理 App

**衡账是一款给律师个人使用的律师费用管理 App。** 每个案件约定收多少、开票多少、到账多少、还有多少未付，都能集中查看。

律师费分几次收、发票分几次开，案子一多，核对起来就费时间。我开发衡账，希望让同行少花些时间翻台账，把每笔费用记清楚。

**当前为 1.0.8 单机版，支持 Mac。** 数据保存在自己的电脑，日常记账可以离线完成，存储、备份和恢复由自己掌握。

## 能做什么

- **收费约定**：按诉讼、法律顾问、专项案件登记客户和律师费。
- **开票与到账**：登记开票金额、逐笔记录到账，汇总查看，在工作台掌握整体费用情况，标记待开票事项。
- **案件节点**：记录案件进展，记下完成立案、一审判决书出具等重要事项。
- **顾问续签**：查看顾问到期提示，创建续签案件。
- **导入导出与备份**：支持 Excel 台账导入、导出，每 48 小时自动备份，保留最近 5 份本机备份，支持完整备份与恢复。
- **工作台格言**：可在“设置与备份”中自定义，也可恢复默认。

## 下载与安装

不妨先从一个案件开始，把收费约定、开票和到账记下来，看看是否顺手。欢迎同行试用，也欢迎告诉我哪些地方还不好用。

打开[安装包下载页](https://github.com/pansong-law/hengzhang-open/releases/latest)，下载通用版 DMG，双击打开，将“衡账.app”拖入“应用程序”。支持 macOS 13 及以上，兼容 Apple 芯片和 Intel Mac，App 自带运行环境。

## 首次打开的来源验证提示

衡账当前使用本地 ad-hoc 签名，Apple Developer ID 签名和公证尚待完成。首次从 GitHub 下载后，Mac 可能提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”。确认安装包来自本项目发布页后，可按以下步骤打开：

1. 将“衡账.app”拖入“应用程序”，先双击打开一次。
2. 出现来源验证提示时，点击“完成”或“取消”，保留 App。
3. 打开苹果菜单 →“系统设置”→“隐私与安全性”。
4. 在安全性区域找到“衡账”被阻止的提示，点击“仍要打开”。
5. 按系统要求通过 Touch ID 或 Mac 登录密码确认，再点击“打开”。

如果没有“仍要打开”入口，或操作后仍无法启动，可将完整提示发给开发者协助处理。提示“已损坏”时，先重新下载安装包并核对发布页的 SHA-256；提示明确检测到恶意软件或“会损坏电脑”时，联系开发者核查。

## 台账和费用

诉讼、法律顾问、专项使用各自的字段和 Excel 模板。承办、协办律师按姓名填写。

未付金额、开票未付金额支持自动计算和手动登记。开票未付金额留空时按累计开票减累计已收款计算，最低为零；手填后以登记值为准，清空可恢复自动计算。

Excel 导出保留金额的“自动／手填”计算方式。重新导入时，“自动”按台账数据计算，“手填”按登记值保存。旧表缺少计算方式列或该列留空时，沿用非空金额的导入规则。

导入前可预览新增、合并和校验结果。相同内部案号合并非空字段，无案号时新建；导入读取第一张工作表。导出按业务类型分工作表，需要逐表导入时可将各工作表分别保存为文件。

待开票事项由使用者登记和完成；实际开票、到账分别维护。顾问续签创建独立案件，继承客户与服务约定，费用和流水从新一期开始记录。

## 数据与备份

默认数据目录为 ~/Library/Application Support/Hengzhang Local/，可在“设置与备份”打开。案件、收款流水、进展、提醒和格言设置保存在独立目录，替换 App 后继续保留。

首次启动生成一份备份，此后在应用运行期间每 48 小时自动备份一次。重启沿用上次备份时间；再次打开时如已满 48 小时，会补做一次。可随时点击“导出备份”，将带完整性校验的 JSON 文件另存到自己选择的位置。

自动、手动及恢复前快照合计保留最近 5 份本机备份；自行导出到其他目录的文件按自己的备份计划保存。建议将重要备份另存到其他设备。

完整备份包含全部案件及相关历史记录。恢复前会显示内容数量，经确认后整体替换当前数据，并先保留恢复前快照。Excel 用于台账交换，完整历史通过 JSON 备份保存和恢复。

数据库无法读取时，App 提供选择完整备份恢复的入口，原文件保留在数据目录的 recovery 子目录。保存后若磁盘持久性确认失败，程序会暂停后续写入并提示核对；退出并重新打开衡账，确认本次更改后再继续登记。

## 软件更新

App 首次启用自动检查时检查新版本，此后每 48 小时自动检查一次；再次启动沿用检查时间。也可在“设置与备份”或“衡账”菜单中手动检查，自动检查可在设置中关闭。

更新信息来自 [pansong-law/hengzhang-open](https://github.com/pansong-law/hengzhang-open) 的 GitHub Releases，版本检查使用匿名请求。发现新版本后，可查看更新说明并前往下载页。下载完成后退出衡账，替换 App。升级前建议导出完整备份。

1.0.8 使用新的仓库地址。使用早期版本的用户，可从上述下载页手动安装一次 1.0.8，以继续接收新版提醒。

## 开发与验证

开发环境需要 Node.js 22 或更高版本。

| 命令 | 用途 |
| --- | --- |
| npm ci | 安装开发依赖 |
| npm start | 启动桌面应用 |
| npm run dev:server | 启动浏览器开发服务 |
| npm test | 验证数据、金额、导入、备份恢复、更新和发布快照 |
| npm run test:desktop | 在 Electron 窗口中验证业务与文件操作 |
| npm run pack:mac | 构建 Mac 通用版 App |
| npm run dist:mac | 生成 Mac 通用版 DMG |

测试使用系统临时目录中的独立数据。验证实际打包 App 时，将 HZ_APP_EXECUTABLE 设为 App 内的 Contents/MacOS/衡账，再运行 npm run test:desktop。

### 发布版本

1. 使用 npm version 新版本号 --no-git-tag-version 更新版本。
2. 运行 npm test、npm run dist:mac，并验证实际打包 App。
3. 在系统临时目录准备更新说明 Markdown，运行 npm run release:preview -- --allow-public 核对版本、目标仓库和源码范围。
4. 运行 npm run release -- --allow-public --notes /绝对路径/更新说明.md。脚本校验源码快照、安装包和签名后，提交源码、创建版本标签、上传 DMG 与 SHA-256 校验文件，并核对远端安装包。

发布目标为 pansong-law/hengzhang-open，需要具有仓库写入权限的 GitHub CLI 登录状态。每个版本使用独立版本号和标签，发布过程从规定的源码清单生成快照。
