# 衡账｜给律师用的律师费管理应用

**衡账是一款给律师个人使用的律师费用管理应用。** 每个案件约定收多少、开票多少、到账多少、还有多少未付，都能集中查看。

律师费分几次收、发票分几次开，案子一多，核对起来就费时间。我开发衡账，希望让同行少花些时间翻台账，把每笔费用记清楚。

**当前为 1.0.8 单机版，支持 Mac。** 数据保存在自己的电脑，日常记账可以离线完成，存储、备份和恢复由自己掌握。

## 能做什么

- **收费约定**：按诉讼、法律顾问、专项案件登记客户和律师费。
- **开票与到账**：登记开票金额、逐笔记录到账，汇总查看，在工作台掌握整体费用情况，标记待开票事项。
- **案件节点**：记录案件进展，记下完成立案、一审判决书出具等重要事项。
- **顾问续签**：查看顾问到期提示，创建续签案件。
- **导入导出与备份**：支持 Excel 台账导入、导出，每 48 小时自动备份，保留最近 5 份本机备份，支持完整备份与恢复。
- **工作台格言**：可在“设置与备份”中自定义，也可恢复默认。

### 工作台：先看费用，再看待办

签约律师费、累计已收款、未付金额和开票未付金额集中显示；下方列出待开票事项、顾问到期提示和按业务类型汇总的费用，打开应用就能查看。

### 案件台账：一张表核对每个案件的费用

诉讼、顾问和专项案件放在同一张台账里，可按类型、状态、费用情况筛选，也可搜索客户、案号或案由。右侧可直接编辑、登记到账、标记待开票和记录进展；顾问案件还可续签。

### 登记到账：只填这次收到的钱

点击“到账”，填写本次金额、到账日期和备注。示例中累计已收款为 25,000 元，本次填写 8,000 元；保存后累计已收款变为 33,000 元，并留下一笔收款流水，便于以后核对。

![登记到账：填写本次到账金额、日期和备注，全部为模拟数据](docs/screenshots/03-register-payment.png)

### Excel 导入：沿用已有台账

点击“导入台账”，按诉讼、顾问或专项下载对应模板，填好后选择文件。系统先预览新增、合并和校验结果，确认后再写入；相同内部案号合并非空字段，没有案号的记录新建。

![Excel 导入：三类业务模板及导入入口](docs/screenshots/04-excel-import.png)

### 设置与备份：保存完整记录，换电脑也能恢复

“导出备份”保存全部案件、收款流水、进展、提醒和格言设置；“选择备份文件”先预览，再确认恢复。应用运行期间每 48 小时自动备份，本机合计保留最近 5 份，也可从列表中预览与恢复。

![数据备份：导出完整备份、选择备份文件及本机快照恢复，全部为模拟数据](docs/screenshots/05-backup-settings.png)

## 常用按钮怎么用

| 按钮或入口 | 用途 |
| --- | --- |
| **＋ 新建案件** | 选择诉讼、顾问或专项，登记客户、收费约定及案件信息。 |
| **案号、客户或案件名称** | 点击台账中的文字打开案件详情，查看费用、收款流水和进展。 |
| **编辑** | 修改案件信息、累计开票金额和收费约定；未付金额、开票未付金额可自动计算或手填。 |
| **到账** | 增加一笔实际收款，填写本次金额，保存后累加至已收款；不要填成累计金额。 |
| **应付** | 标记或查看待开票提醒，记录付款节点、金额和说明；完成提醒不会自动增加开票或到账金额。 |
| **进展** | 记录立案、开庭、判决、交付等节点，保留可回看的进展记录。 |
| **续签** | 仅用于顾问案件，创建独立的新一期案件，继承客户与服务约定，费用和流水重新开始记录。 |
| **导入台账／下载模板** | 下载对应业务模板，选择 Excel 文件，预览并确认导入。 |
| **导出当前筛选／导出全部台账** | 前者只导出筛选结果，后者导出全部案件；按业务类型分工作表。 |
| **导出备份** | 保存包含全部案件及历史记录的完整 JSON 备份，可另存到其他设备。 |
| **选择备份文件／预览与恢复** | 从外部备份或本机快照预览内容，确认后整体替换当前数据，恢复前先保留保护快照。 |
| **检查更新** | 手动检查新版，查看说明并前往 GitHub 下载；检查版本时不上传案件数据。 |
| **保存格言／恢复默认** | 自定义工作台首页文字，或恢复“热爱法律，笃行正义。”。 |

从一件案件开始，可以依次完成：**新建案件 → 登记收费与开票金额 → 每次收款点“到账” → 重要节点点“进展” → 导出备份**。Excel 导出用于台账交换，完整历史记录请用 JSON 备份保存。

## 下载与安装

不妨先从一个案件开始，把收费约定、开票和到账记下来，看看是否顺手。欢迎同行试用，也欢迎告诉我哪些地方还不好用。

打开[安装包下载页](https://github.com/pansong-law/hengzhang-open/releases/latest)，下载通用版 DMG，双击打开，将“衡账.app”拖入“应用程序”。支持 macOS 13 及以上，兼容 苹果芯片和英特尔芯片的 Mac，应用自带运行环境。

## 首次打开的来源验证提示

衡账当前使用本地临时签名（ad-hoc），Apple Developer ID 签名和公证尚待完成。首次从 GitHub 下载后，Mac 可能提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”。确认安装包来自本项目发布页后，可按以下步骤打开：

1. 将“衡账.app”拖入“应用程序”，先双击打开一次。
2. 出现来源验证提示时，点击“完成”或“取消”，保留应用。
3. 打开苹果菜单 →“系统设置”→“隐私与安全性”。
4. 在安全性区域找到“衡账”被阻止的提示，点击“仍要打开”。
5. 按系统要求通过 触控 ID（Touch ID）或 Mac 登录密码确认，再点击“打开”。

如果没有“仍要打开”入口，或操作后仍无法启动，可将完整提示发给开发者协助处理。提示“已损坏”时，先重新下载安装包并核对发布页的 SHA-256；提示明确检测到恶意软件或“会损坏电脑”时，联系开发者核查。

## 台账和费用

诉讼、法律顾问、专项使用各自的字段和 Excel 模板。承办、协办律师按姓名填写。

未付金额、开票未付金额支持自动计算和手动登记。开票未付金额留空时按累计开票减累计已收款计算，最低为零；手填后以登记值为准，清空可恢复自动计算。

Excel 导出保留金额的“自动／手填”计算方式。重新导入时，“自动”按台账数据计算，“手填”按登记值保存。旧表缺少计算方式列或该列留空时，沿用非空金额的导入规则。

导入前可预览新增、合并和校验结果。相同内部案号合并非空字段，无案号时新建；导入读取第一张工作表。导出按业务类型分工作表，需要逐表导入时可将各工作表分别保存为文件。

待开票事项由使用者登记和完成；实际开票、到账分别维护。顾问续签创建独立案件，继承客户与服务约定，费用和流水从新一期开始记录。

## 数据与备份

默认数据目录为 ~/Library/Application Support/Hengzhang Local/，可在“设置与备份”打开。案件、收款流水、进展、提醒和格言设置保存在独立目录，替换应用 后继续保留。

首次启动生成一份备份，此后在应用运行期间每 48 小时自动备份一次。重启沿用上次备份时间；再次打开时如已满 48 小时，会补做一次。可随时点击“导出备份”，将带完整性校验的 JSON 文件另存到自己选择的位置。

自动、手动及恢复前快照合计保留最近 5 份本机备份；自行导出到其他目录的文件按自己的备份计划保存。建议将重要备份另存到其他设备。

完整备份包含全部案件及相关历史记录。恢复前会显示内容数量，经确认后整体替换当前数据，并先保留恢复前快照。Excel 用于台账交换，完整历史通过 JSON 备份保存和恢复。

数据库无法读取时，应用提供选择完整备份恢复的入口，原文件保留在数据目录的 recovery 子目录。保存后若磁盘持久性确认失败，程序会暂停后续写入并提示核对；退出并重新打开衡账，确认本次更改后再继续登记。

## 软件更新

应用首次启用自动检查时检查新版本，此后每 48 小时自动检查一次；再次启动沿用检查时间。也可在“设置与备份”或“衡账”菜单中手动检查，自动检查可在设置中关闭。

更新信息来自 [pansong-law/hengzhang-open](https://github.com/pansong-law/hengzhang-open) 的 GitHub Releases，版本检查使用匿名请求。发现新版本后，可查看更新说明并前往下载页。下载完成后退出衡账，替换应用。升级前建议导出完整备份。

1.0.8 使用新的仓库地址。使用早期版本的用户，可从上述下载页手动安装一次 1.0.8，以继续接收新版提醒。

## 开发与验证

开发环境需要 Node.js 22 或更高版本。

| 命令 | 用途 |
| --- | --- |
| npm ci | 安装开发依赖 |
| npm start | 启动桌面应用 |
| npm run dev:server | 启动浏览器开发服务 |
| npm test | 验证数据、金额、导入、备份恢复、更新和发布快照 |
| npm run test:desktop | 在 Electron 窗口中验证业务与文件操作 |
| npm run pack:mac | 构建 Mac 通用版应用 |
| npm run dist:mac | 生成 Mac 通用版 DMG |

测试使用系统临时目录中的独立数据。验证实际打包应用 时，将 HZ_APP_EXECUTABLE 设为 应用内的 Contents/MacOS/衡账，再运行 npm run test:desktop。

### 发布版本

1. 使用 npm version 新版本号 --no-git-tag-version 更新版本。
2. 运行 npm test、npm run dist:mac，并验证实际打包应用。
3. 在系统临时目录准备更新说明 Markdown，运行 npm run release:preview -- --allow-public 核对版本、目标仓库和源码范围。
4. 运行 npm run release -- --allow-public --notes /绝对路径/更新说明.md。脚本校验源码快照、安装包和签名后，提交源码、创建版本标签、上传 DMG 与 SHA-256 校验文件，并核对远端安装包。

发布目标为 pansong-law/hengzhang-open，需要具有仓库写入权限的 GitHub CLI 登录状态。每个版本使用独立版本号和标签，发布过程从规定的源码清单生成快照。
